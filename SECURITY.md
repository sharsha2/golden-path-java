# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's
[Report a vulnerability](https://github.com/sharsha2/golden-path-java/security/advisories/new)
form (Security tab -> Advisories). Do not open a public issue.

I aim to acknowledge reports within 7 days.

## Supported versions

Only the latest commit on `main` is supported.

## Scope

This is a learning and portfolio project, not production software. `Dockerfile.naive`
is intentionally insecure and exists only for comparison against `Dockerfile`.

See the [CI pipeline](https://github.com/sharsha2/golden-path-java/blob/main/.github/workflows/ci.yml)
for the gates every change passes through.
